    Javascript is the "object Based Scripting" language

    Browsers provided so many predefined objects, so we call Javascript is the "object Based"
    1) document
         used to manipulate the "html elements"

         when ever html loaded into browser  engine successfully, automatically document/DOM object/documnet object 
         model will create by Browser

         DOM object internally contains tree structure/hirarichal structure called as "DOM Tree structure"

         navigation inside DOM object called as "DOM Tree Traversing"

         doing changes in DOM Object called as DOM "Manipulation"

    2) console
         console object,used to debug Javascript application 
        
    3) window
         window object is the super object / master object
         window object, used to work with browser properties
         ex.
               window width
               window height
               number of tabs
               --------
               --------

    4) date
         used to work with the Calender
         ex. 
            x = new date();
            document.write(x);
            console.log(x);
            above snippet, used to get current date (today)

    5) Time
        used to work with timer

    6) local storage
          browser supports twwo types of storages
            1) Local storage
            2) session storage

            local storage object,used to work with the browser local storage
            session storage object,used to work with Browser sessionStorage

                Rules for Identifier
                ********************
                1) identifier must have a-z, A-Z, 0-9, $ and _
                2) identifier should not start with digits
                Ex.
                     var 123abc  (wrong)
                     var _abc123  (right)
                     var _123abc  (right)
                     var _123$abc  (right)
                     var _123#abc  (wrong)
